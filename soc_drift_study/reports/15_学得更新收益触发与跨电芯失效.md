# 15. 从“漂移检测”到“更新价值预测”：8 电芯回顾性挑战及研究路线冻结

已完成 GitHub Actions [38205374544](https://github.com/Ustinian1722/eVTOL-SOC/actions/runs/38205374544)。脚本 `scripts/learned_mission_update_value.py`，合成单元测试 5/5，通过完整 22 电芯工作流中开发14／挑战8 电芯的双层研究。

**技术目标：**普通飞行数据判断执行哪一次 SOC 自适应**会真正有价值**。低倍率 RPT 不参加运行期检测或模型更新。与纯无监督阈值不同，本次允许用历史源电芯的 SOC_proxy 结果离线训练一个效益预判模型；该源标签本身由过去 RPT 容量和库仑积分定义，必须明确区分“源端离线监督”与“目标端在线无 RPT 更新”。测试电芯初始 N20 SOC Ridge 则只采用标称 3Ah 任务电量积分。

## 研究方案

- 基础 HOW：先前验证过的**任务内 ΔQ 守恒+N20 源监督知识保护**的 Ridge 小步更新。
- 运行期可观测价值特征（共 13 个）：候选在已完成任务的留组相对物理损失下降、源域性能保护、预测位移、训练任务电压误差、趋势、电压/温度/电流和任务内 ΔQ 统计。不使用目标 SOC_proxy、未来循环或 RPT。
- 源训练：14 个固定开发电芯，离线对每个决策点构建“是否改善**后续50次任务代理 MAE**”的历史监督信号，正类门槛为至少 0.05 pp 改善。统一标准化 LogisticRegression(C=0.4, class_weight='balanced')。用 group-by-physical-cell 的 5 折开发验证。
- 挑战：由**电芯 ID 预设哈希**确定的另 8 个电芯。模型权重及分类参数只从开发 14 芯拟合，挑战流严格逐任务预测后更新。候选门槛 0.50/0.65/0.80 预先指定，不从挑战标签择优。
- 所有方法上限 B=4 次**尝试**，实际被接受更新数不同；周期基线每150任务一次（部分短电芯不足4次）。不能将其当作严格配平更新次数的最终 WHEN 实验。
- **重要：全 22 电芯都在之前的其他实验中被研究过，所以这是代码上分离的回顾性挑战，不能称为“从未见过的独立外测”。**

## 开发域与挑战域：预测更新收益的泛化失败

| 指标 | 结果 |
|---|---:|
| 开发电芯 | 14 |
| 开发反事实更新候选数 | 541 |
| 开发正收益占比 | 328/541（60.6%） |
| 开发电芯留组 ROC-AUC | 0.739 |
| 开发电芯留组 AP | 0.823 |
| **8 挑战电芯合并 ROC-AUC** | **0.495** |
| 挑战正收益占比 | **90.4%** |

其中挑战芯 VAH02、VAH20、VAH22 的候选收益全部为正，单芯 ROC-AUC 无法定义；VAH27 的 AUC 只有约 0.056。跨群特征分布也发生变化：挑战组任务内 ΔQ 均值相对开发组变化约 1.13 个开发标准差，ΔQ 标准差差异约 0.74 SD，其余源约束退化、电压残差也存在明显变化。说明开发组学到的“收益概率”跨工况泛化脆弱，不适合当前直接部署。

## 挑战 8 电芯真实在线回放（初始 N20 纯任务库仑积分，不使用 RPT 更新）

| 更新策略 | SOC_proxy MAE 电芯中位数（pp） | 相对冻结的平均变化（pp） | 95% cell Bootstrap 区间（pp） | 改善电芯 |
|---|---:|---:|---:|---:|
| 冻结 Ridge | 2.897 | 0 | [0,0] | — |
| **周期150任务更新** | **1.875** | **−1.374** | [−2.013,−0.763] | 7/8 |
| 简单物理损失收益门控 | 2.325 | −0.470 | [−0.855,−0.131] | 6/8 |
| 学习效益门控 p≥0.50 | 2.430 | −0.442 | [−0.736,−0.195] | 8/8 |
| 学习效益门控 p≥0.65 | 2.787 | −0.284 | [−0.492,−0.110] | 7/8 |
| 学习效益门控 p≥0.80 | 2.785 | −0.092 | [−0.228,+0.025] | 4/8 |

周期策略的更新次数中位数为3/3，而学习门控0.50和0.65约为4/4。尽管周期更新数更少，当前仍显著优于学到的价值触发。**主动 WHEN 在本阶段必须判定 NO-GO**，不能因为学习型触发器优于 Frozen 就说它具有主动性收益。

## 统一研究决策（考虑上一轮强 GRU 反证）

三组实测结论必须共同解释：

1. **HOW-positive，弱局部模型成立：**使用普通任务 ΔQ 约束，对目标 N20 Ridge 具有可重复代理精度改善，不需要执行新的低倍率 RPT。
2. **HOW-negative，强源模型不成立：**先前5折3种子跨电芯 GRU 冻结 SOC_proxy MAE 约 **1.187 pp**，简单在线容量斜率适配通常将其恶化（详见报告14）；不允许把弱模型的更新成功写成对强模型的普遍优势。
3. **WHEN-negative：**电压残差、物理一致性、基于历史 ROI 的学习型触发均未在合法预算对照中稳定优于周期更新；源域效益分类器 ROC-AUC 0.739 跌至挑战域 0.495，提示何时更新的信息目前不可迁移。

**建议研究主线：暂停随机增加触发器和无监督损失。优先研究能否在非 RPT 常规工况下对强跨电芯预训练模型做真正有意义的低成本漂移校准（输入域、老化容量先验、共享电压自监督、受控残差 adapter），需要强 Frozen GRU 和同样预算的周期对照。**一旦强模型层面的有效 HOW 不存在，就不投入更多主动 WHEN 预算；可将任务重新限定在仅有目标初期少量样本的部署场景，并且明确局部 N20 与跨电芯丰富源数据的不同条件。强模型不可轻易改差这一负结果应永久保留。
