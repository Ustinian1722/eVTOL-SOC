# 报告42：22颗VAH电芯截止样终点的时长一致性与参考可辨识性审计（2026-10-31）

## 研究对象与协议

本轮只对报告41已经逐采样匹配的22颗原始VAH VTC6电芯、20,848次正常Ns4/5/6高倍率任务做新的**时长一致性再分析**。将每颗电芯**前80%任务时长的中位数**作为该电芯固定工况时长的描述性基线，避免将9.67、13.00、16.33、19.67分钟等不同协议混为一谈。分析原始Ns6末端电压/温度、最后记录任务与相对时长缩短，不修改任何原始CSV、SOC_proxy、固定HOW或WHEN策略。

## 新发现

| 审计指标 | 22芯结果 |
|---|---:|
| 正常任务 | 20,848 |
| 末端电压≤2.55 V或温度≥69°C的严格筛查候选 | 94 |
| 上述候选中并非最后记录任务 | **77** |
| 77个非最后候选涉及的电芯 | **VAH07、VAH10** |
| 末端电压位于2.50±0.01 V | 21 |
| 其中为该电芯最后记录任务 | 16 |
| 最后任务+近2.5 V+较同芯早期时长缩短>10秒 | **15** |
| 全部任务中缩短>10秒但不满足上述联合条件 | 1 |

**阈值筛查不能直接代表终止事件。** 77/94个严格候选是VAH07、VAH10上的非最后记录任务，且没有任何一次相对同芯早期时长基线缩短超过10秒。VAH07的充电峰值协议约4.0 V，VAH10的高温候选发生在正常时长任务中。阈值附近的负载端电压/温度并不是独立的保护动作原因码。

**联合证据更强，但仍非真值。** 15个最后记录任务同时满足末端2.50±0.01 V及缩短>10秒，缩短幅度约29.7–59.3秒，与寿命末期提前截止相一致。VAH07最后记录任务虽接近2.50 V，却没有明显缩短；另有一个非最后任务缩短约25秒，但没有低压或高温终点信号。

| 时长缩短阈值 | 全部任务 | 最后任务近2.5 V | 非最后任务近2.5 V |
|---:|---:|---:|---:|
| >5 s | 16 | 15 | 0 |
| >10 s | 16 | 15 | 0 |
| >20 s | 16 | 15 | 0 |
| >30 s | 14 | 14 | 0 |
| >45 s | 11 | 11 | 0 |
| >60 s | 0 | 0 | 0 |

这是在同一批反复研究的22颗电芯上开展的**描述性回顾性审计**，不提供全新独立测试或统计意义上的保护动作识别准确率。以上阈值为探索性定义，不能被当作官方终止原因。

## 对监督参考可获得性的影响

现有数据支持“正常任务主要按照各自预设时长执行，少量寿命末期任务呈现截止样终点”。但是即便15个联合候选是真正提前终止，也不能独立证明：本次充电后SOC精确为100%、充电终止规则已统一、末端触发了哪一项保护、完整高倍率可用容量已按诊断协议测量、或者该诊断可在任意寿命时点按需付费执行。

历史SOC_proxy的分母依赖先前RPT容量，不能称RPT-free或独立高倍率真实SOC。当前购买正常任务SOC_proxy曲线的成本λ及其他处理成本都是**假设效用单位**，不能称真实人民币、人工工时或农业无人机停机成本。没有农业现场验证。

**GO：** 将联合时长/终点证据作为数据协议、参考可辨识性与论文局限性审计。**NO-GO：** 将15个候选截止任务直接当作已验证的高倍率完整诊断监督标签，或据此继续调整HOW/WHEN模型。
