# 报告41：22颗原始VAH电芯正常高倍率任务的终止条件与充电衔接审计（2026-10-30）

## 研究问题与数据边界

针对报告40尚未核实的问题，本轮实际读取全部22颗原始VAH VTC6电芯CSV，包括3颗Git LFS电芯。依据已经审计的正常任务Ns4/5/6分段，逐任务精确匹配原始Ns4首点、Ns6末点（时间戳误差≤0.001秒，且Ns相同），拒绝模糊或重复命中。原始CSV、SOC_proxy、冻结HOW、WHEN采购策略、预算均未改变。本轮是**原始数据终止条件审计**，不是重新训练或新电芯外部验证。

成功CI：[GitHub Actions #41011024618](https://github.com/Ustinian1722/eVTOL-SOC/actions/runs/41011024618)。Artifact包含20,848条逐任务原始末端记录、逐芯CSV、候选事件CSV、充电衔接CSV、三个自动生成的中文报告及元数据。

## 1. 原始Ns6末端核验：不是所有任务都放至截止，但确实存在截止样事件

| 指标 | 结果 |
|---|---:|
| 物理电芯 | 22 |
| 有效正常高倍率任务 | 20,848 |
| Ns4首点与Ns6末点均精确匹配 | 20,848 |
| 未匹配或歧义 | 0 |
| Ns6末端电压中位数 | 2.9579 V |
| 末端电压≤2.60 V（宽松筛查） | 140 |
| 末端电压≤2.55 V（较严格筛查） | 53（16颗电芯） |
| 末端温度≥69°C | 41（仅VAH10） |
| 严格候选并集：≤2.55 V或≥69°C | **94次，17颗电芯** |
| 宽松候选并集：≤2.60 V或≥69°C | **181次** |

**重要纠正：** 不能说“原始正常高倍率任务完全没有放到截止的记录”。末端约2.500 V的实际采样点确实存在；有21次任务末端落在2.50±0.01 V，涉及16颗电芯。16颗电芯的最后一次有效正常任务均出现此类近2.5 V终点；另有VAH10末次任务达到高温候选阈值。这更符合电芯寿命末期触发试验终止的可能情景，而非所有任务都固定放电至截止。

94次严格候选中，80次发生在对应电芯后10%任务序列；53次≤2.55 V中39次处于后10%。VAH07出现38次≤2.55 V，VAH10出现41次≥69°C，不能把这些重复事件误算成38或41颗独立电芯。

2.60/2.55 V与69°C是探索性筛查阈值，**不是独立终止原因码**。低电压可能是负载瞬态或任务结束时的端电压；高温也不自动证明保护动作已触发。需结合官方协议、阶段持续时间和独立结束原因进一步核验。

## 2. 先前充电与满充起点

利用与任务相同的 `charge_cycle_index`，核对Ns0持续充电块结束时间必须早于Ns4任务开始。

| 指标 | 全部20,848次任务 | 94次严格截止样候选 |
|---|---:|---:|
| 能匹配时序正确的先前Ns0充电块 | 20,848 | 94 |
| 充电段峰值电压≥4.0 V | 20,587 | 56 |
| 充电段峰值电压≥4.1 V | 19,995 | 55 |
| 充电段峰值电压≥4.18 V | 19,899 | 55 |
| 充电段峰值电压中位数 | 4.200 V | 4.200 V |
| 充电结束到任务开始间隔中位数 | 62.51 min | 70.59 min |

原始Ns4开始时端电压中位数约3.949 V，任务放电计数起点接近0 Ah。**必须纠正一个潜在误判：不能用高倍率Ns4加载后的端电压是否≥4.1 V判断是否满充。** 负载极化会降低端电压；充电段峰值4.2 V与Ns4起点约3.95 V并不矛盾。起始放电计数约0只说明计数重置，不等于独立SOC=100%测量。

Ns0充电块及峰值电压是充电过程的证据，但还没有逐任务独立确认充电终止规则、充电结束的静置OCV、统一SOC初值、温度影响和诊断容量定义。

## 3. 与报告40的表面矛盾如何解释？

报告40得到正常任务的累计放电量相对于历史低倍率RPT容量中位数62.44%，最大82.47%，没有任务达到历史容量95%。

本轮发现一部分末端电压约2.5 V的正常高倍率任务；这两者**并不矛盾**：高倍率放电的电压极化可能使电芯在尚未释放低倍率参考容量时提前达到端电压截止。严格截止样候选的 `Q_end/历史RPT容量` 中位数约0.668，接近2.5 V候选的中位数约0.654。

但是，**触及2.5 V的正常任务≠专门购买的高倍率完整诊断维护**。这批数据没有额外按需维护实验的成本、监督参考质控或独立同倍率容量真值。不能把这些历史寿命末期事件直接替代任意寿命时点都可购买的诊断参考，也不能据此把当前WHEN回放解释为真实农业无人机维护效率。

## 4. 对论文主线的决策

**GO：** 保留“普通高倍率任务以固定任务时长为主，但部分寿命末期任务出现实际低电压/高温截止样终点”的原始数据证据；将本轮逐芯、逐任务审计用于修正论文的数据协议描述与参考可得性边界。

**NO-GO：** 不把全部普通任务说成100%→0%满充满放；不把末端2.5 V事件说成已验证的高倍率独立SOC真值；不把正常任务部分SOC_proxy标签解锁成本称作真实完整诊断停机成本；不因本轮结果再次更改HOW或调WHEN网络。

后续如果仍只用22颗电芯，论文应把“正常任务SOC_proxy参考按需解锁”作为**有条件的历史反事实监督采购研究**，而不是虚构额外高倍率完整放电的现场实验。所有结论继续限定为RPT容量锚定的SOC_proxy和假设维护效用成本。
